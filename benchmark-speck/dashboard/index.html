Dashboard Benchmarking SPECK64/128 pada Perangkat IoT

ESP32-S3 + GY-BME280 (sintetis, sensor fisik belum terpasang) · SPECK-CTR + HMAC-SHA256

Non-real-time — data dimuat sekali, tidak auto-refresh
Dashboard ini membaca dashboard/summary.json yang dihasilkan oleh analyze.py. Sesuai desain penelitian, dashboard TIDAK melakukan polling otomatis — jalankan ulang python analyze.py setelah sesi pengujian baru, lalu klik “Muat Ulang Data”. Penggunaan CPU/RAM ditampilkan adalah proses server.py di komputer host, bukan pengukuran langsung pada mikrokontroler ESP32-S3.
